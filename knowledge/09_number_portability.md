# Number Portability

Customers joining Alpine Mobile can normally keep an existing Swiss mobile number.

Required information:
- mobile number to transfer;
- current provider;
- name of current contract holder;
- requested transfer date.

The information must match the current provider's records.
Early transfer does not automatically remove contractual obligations with the previous provider.
