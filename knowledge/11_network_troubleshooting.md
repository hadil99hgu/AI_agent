# Mobile Network Troubleshooting

If there is no mobile network connection:
1. Check that airplane mode is disabled.
2. Restart the phone.
3. Confirm that the SIM or eSIM is active.
4. Set mobile network selection to automatic.
5. Check network coverage.
6. Check the live network-status service for incidents.
7. Test the SIM in another compatible device when practical.

For mobile data issues, verify mobile data, APN settings and roaming settings.

Live outage information must come from the network-status API, not this static document.
